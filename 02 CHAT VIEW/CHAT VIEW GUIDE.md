# Chat View

Chat messages are represented using Obsidian callouts:

```md
> [!assistant] Gaspar
> Mensaje del agente.

> [!user] Tú
> Respuesta del usuario.
```

A CSS snippet can style these callouts as bubbles. Treat the note body as source content; commentary should be append-only unless a user explicitly authorizes edits. The custom plugin is experimental and must be tested in Obsidian before being trusted with important notes.
