# FIRST LAUNCH

1. Clone the repository and open its root as an Obsidian vault.
2. Confirm the eight numbered GASPAR folders exist, from `00_START HERE` through `07_ARCHIVE`.
3. Read `AGENTS.md` and `01_WIKI/README.md` before granting write access.
4. Review community plugin source before enabling it.
5. Enable the bundled theme or CSS snippet in Obsidian settings as appropriate.
6. Test agent write permissions in a disposable note under `04_PLAYGROUND-OUTPUTS/`, never with production notes.
7. Legacy bootstrap folders are noncanonical; do not create new root-level categories.

Drive's GASPAR directory is the architecture authority; the GitHub bootstrap must remain sanitized and must not copy private content.
