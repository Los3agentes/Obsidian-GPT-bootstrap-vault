# FIRST LAUNCH

1. Clone this repository and open its root as a vault in Obsidian.
2. Review `AGENTS.md` and `WIKI/FOLDER AUTHORITY.md` before enabling any agent write access.
3. Enable community plugins only after reviewing their source and trusting the code.
4. Enable the bundled CSS snippet or theme from Obsidian settings when installed.
5. Configure a dedicated test folder for local filesystem access. Never grant whole-disk access by default.
6. Verify agent write operations with a disposable `GASPAR_TEST.md` before production use.

See [[WIKI/HOME]] for documentation.
