# Obsidian GPT Bootstrap Vault

Sanitized bootstrap aligned with the canonical eight-folder GASPAR architecture on Google Drive.

## Canonical root

- `00_START HERE/`
- `01_WIKI/`
- `02_USER/`
- `03_SYSTEM/`
- `04_PLAYGROUND-OUTPUTS/`
- `05_CAPTURE/`
- `06_RESOURCES/`
- `07_ARCHIVE/`

The `.obsidian/` directory is technical configuration, not a ninth knowledge folder.

Begin with [FIRST LAUNCH](FIRST%20LAUNCH.md), [Wiki](01_WIKI/README.md), and [AGENTS](AGENTS.md).

Legacy folders (`WIKI/`, `01 LOCAL AGENT/`, `02 CHAT VIEW/`, `03 THEME/`, `04 CODING SKILLS/`) are retained temporarily to avoid data loss; they are **not** canonical. Migrate their contents after verifying all paths and links. Never invent or rename canonical roots.
